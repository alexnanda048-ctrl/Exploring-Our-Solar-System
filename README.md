# Exploring-Our-Solar-System

## Project Option
Website

## Project Description
This website is intended to teach kids about the solar system and provide an end of page quiz.

## Theme Interpretation
The theme of my website is the solar system, specifically through the lens of early education

## Intended User or Player
Children in roughly the 3rd-7th grade. The content of the website is such that it is likely being presented to them by a teacher or parent for additional supplemental material.

## User or Player Goal
The player should be able to retain the information presented on the website to pass the end of site quiz.

## Main Features
The major features includes the header, navigation bar, flashcard links, drop-downs containing relevant information, fun facts flashcards, and the end of site quiz, as well as the resources and the footer.

## JavaScript Features
Javascript is used in a variety of ways. For one it used to trigger the drop-down boxes when the interactable is clicked. Additionally it is used to load questions, reset the quiz, track the questions and answers and provide feedback for correct and incorrect answers.

## Responsive Design
The project adapts to smaller screens by present information in column format and resizing fonts and images accordingly. 

## User Testing
During testing many mistakes were found. For one the flashcards werent correctly sitting side by side due to a lack of flex. On top of that I found a lot of the website to be to dull. Additionally my peers helped me address certain issues like content bleeding into one another, lack of feedback on the quiz and a non-centered header image.

## Revisions
The first meaningful revision I made was centering my header image so it would appear consistently on larger and smaller screen and improve readability. Additionally I added feedback to the quiz to allow users to better understand the impact of their interactions. Lastly I added additionally spacing and coloring to different content sections to improve clarity and readability. Lastly I increased the size of the font on smaller screens for improved responsiveness.
